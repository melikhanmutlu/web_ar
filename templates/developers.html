Overview

The ARVision API is a small REST API over HTTPS. Requests and responses are JSON, except uploads (multipart) and the CSV analytics export. Successful responses wrap data in a {"data": …} envelope; errors return {"error": "message"} with a 4xx/5xx status.

API access requires a Pro or Business plan; webhooks require Business. Manage your plan on the pricing page.

Authentication

Authenticate every request with a bearer token in the Authorization header. Tokens start with arv_ and carry scopes: models:read, analytics:read, models:write.

curl {{ site_url }}/api/v1/models \
  -H "Authorization: Bearer arv_XXXXXXXXXXXXXXXXXXXX"

Create a token

Create and revoke tokens from your API & webhooks settings. The full token is shown once at creation — store it securely. Pick only the scopes the integration needs.

Rate limits

Limits are per token: 30 requests/minute for uploads (POST /models) and 120 requests/minute for the other endpoints. Responses include X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset; a 429 means you should back off.

List models GET /models

Returns your models (or the organization's, for an org-scoped token). Scope models:read. Query limit (1–100, default 50).

curl "{{ site_url }}/api/v1/models?limit=20" \
  -H "Authorization: Bearer $TOKEN"

Get a model GET /models/{id}

Full detail for one model, including viewer_url and embed_url. Scope models:read.

curl {{ site_url }}/api/v1/models/6f1c… \
  -H "Authorization: Bearer $TOKEN"

Upload & convert POST /models

Upload a model file (STL, OBJ, FBX, GLB/glTF, or a ZIP) as multipart file, with an optional name. Scope models:write. Conversion runs in the background — you get a job to poll. Returns 202.

curl -X POST {{ site_url }}/api/v1/models \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@chair.stl" \
  -F "name=Office Chair"
{
  "data": {
    "job_id": "b2a9…",
    "model_id": "b2a9…",
    "status": "pending",
    "status_url": "{{ site_url }}/api/v1/jobs/b2a9…"
  }
}

Poll a job GET /jobs/{id}

Check conversion progress. Scope models:read. When status is completed, the response adds viewer_url and embed_url. Poll every few seconds, or subscribe to the conversion.completed webhook instead.

{
  "data": {
    "job_id": "b2a9…",
    "status": "completed",
    "model_id": "b2a9…",
    "error": null,
    "progress": 100,
    "viewer_url": "{{ site_url }}/view/b2a9…",
    "embed_url": "{{ site_url }}/embed/b2a9…"
  }
}

Update / delete PATCH /models/{id} DELETE /models/{id}

Scope models:write. PATCH accepts name, description, and visibility (private / unlisted / public). DELETE soft-deletes (moves to trash).

curl -X PATCH {{ site_url }}/api/v1/models/b2a9… \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"visibility": "public", "name": "Office Chair v2"}'

Analytics GET /models/{id}/analytics

Event totals for a model. Scope analytics:read.

{ "data": { "model_id": "b2a9…", "totals": { "view": 128, "ar_launch": 22 } } }

Webhooks

Subscribe an HTTPS endpoint to events from your settings (Business plan). Events:

EventFires when
conversion.completedAn uploaded model finished converting
conversion.failedA conversion gave up after retries
ai_generation.completedAn AI text/image→3D generation finished
ai_generation.failedAn AI generation failed

Deliveries are POSTs with a JSON body {"event": "<type>", "data": {…}} and headers X-ARVision-Event and X-ARVision-Signature: sha256=<hmac>.

Verify signatures

Compute HMAC-SHA256 over the raw request body using your webhook's signing secret, and compare against the X-ARVision-Signature header.

import hmac, hashlib

def verify(raw_body: bytes, header: str, secret: str) -> bool:
    expected = "sha256=" + hmac.new(
        secret.encode(), raw_body, hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, header)
