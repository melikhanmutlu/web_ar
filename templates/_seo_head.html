{# Shared SEO meta partial — mirrors the _security_head.html include convention. Include once per : base.html includes it a single time (shared by every page that extends it — login/register/profile/ my_models/admin/*); each standalone template (index.html, view.html, embed.html, vr.html) includes it individually, right after its own {% include '_security_head.html' %} line. Reads the following from the including template's scope — set via {% set %} before the include ({% include %} inherits the calling context by default). All optional with a safe fallback below. seo_title Used for og:title / twitter:title only — does NOT emit itself; each template keeps its own <title>{{ seo_title }} line so and the OG/Twitter title always match. seo_description ~150-160 char summary. Falls back to a generic site-wide description. seo_canonical Absolute canonical URL. Falls back to SITE_URL + the current request path (self-canonical). seo_robots e.g. 'index, follow' / 'noindex, follow' / 'noindex, nofollow'. FAILS SAFE TO 'noindex, nofollow' when unset — a page must explicitly opt in to being indexed. seo_og_type Open Graph type. Defaults to 'website'. seo_og_image Absolute image URL. When unset, og:image/twitter:image are omitted and the Twitter card falls back to 'summary' instead of 'summary_large_image'. SITE_URL and GOOGLE_SITE_VERIFICATION come from inject_seo_defaults() in app.py and are always in scope. #} {% set _seo_title = seo_title or 'ARVision' %} {% set _seo_description = seo_description or 'ARVision converts 3D models (OBJ, STL, FBX, GLB, GLTF) into instant AR-ready viewer links you can open in augmented reality on iPhone and Android.' %} {% set _seo_canonical = seo_canonical or (SITE_URL + request.path) %} {% set _seo_robots = seo_robots or 'noindex, nofollow' %} {% set _seo_og_type = seo_og_type or 'website' %} <meta name="description" content="{{ _seo_description }}"> <meta name="robots" content="{{ _seo_robots }}"> <link rel="canonical" href="{{ _seo_canonical }}"> {% if GOOGLE_SITE_VERIFICATION %} <meta name="google-site-verification" content="{{ GOOGLE_SITE_VERIFICATION }}"> {% endif %} <meta property="og:site_name" content="ARVision"> <meta property="og:type" content="{{ _seo_og_type }}"> <meta property="og:title" content="{{ _seo_title }}"> <meta property="og:description" content="{{ _seo_description }}"> <meta property="og:url" content="{{ _seo_canonical }}"> {% if seo_og_image %} <meta property="og:image" content="{{ seo_og_image }}"> <meta name="twitter:card" content="summary_large_image"> <meta name="twitter:image" content="{{ seo_og_image }}"> {% else %} <meta name="twitter:card" content="summary"> {% endif %} <meta name="twitter:title" content="{{ _seo_title }}"> <meta name="twitter:description" content="{{ _seo_description }}">
